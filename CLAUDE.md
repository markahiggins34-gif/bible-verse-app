# Verse Finder (bible-app)

Personal PWA: type a topic, get Bible verses (Gemini picks references, NLT API supplies exact text).

## Where things live
- Code (single source of truth): ~/Documents/Claude Files/bible-app  (this folder)
- GitHub: https://github.com/markahiggins34-gif/bible-verse-app (branch main)
- Vercel project: "bible-app" (team markahiggins34-2440s-projects)
  - Live: https://bible-app-sepia-chi.vercel.app  (also bible-app-markahiggins34-2440s-projects.vercel.app)
- Old copies, do not edit: ../bible-app-old-sep16, ~/Documents/Cursor/Bible App (July Next.js version)

## Layout
- public/index.html   whole frontend (HTML + CSS + JS in one file)
- public/tree.svg     opening illustration, generated by scripts/make-tree.js (node scripts/make-tree.js)
- api/verses.js       POST {topic, count 1-10} -> Gemini picks + NLT text
- api/translations.js POST {reference} -> NLT / ESV / NIV / MSG
- api/chapter.js      POST {reference} -> whole chapter in NLT
- api/_lib/bible.js   shared NLT / ESV / api.bible helpers

## Environment variables (set in Vercel, never committed)
GEMINI_API_KEY, NLT_API_KEY (optional, falls back to TEST), ESV_API_KEY, BIBLE_API_KEY

## Deploying
Always commit here first, then deploy from this folder, so live never drifts from the code:
  git push                 # save to GitHub
  npx vercel --prod        # publish (run `npx vercel` without --prod for a test link)
